# Record Usage before deriving cost and stats

Every billable inference attempt will append a normalized Usage Record containing the actual Provider Profile, model, dialect, requested and observed reasoning effort and service tier, provider-reported token and cache classes, cost provenance, and start and completion times. Cost Estimates freeze the Price Schedule used at calculation time, absent provider fields remain unknown rather than inferred as facts, and status-line values plus rolling 1-hour, 1-day, and 7-day distributions and named recurring Usage Windows come from rebuildable Usage Rollups so rendering never scans history or introduces idle polling. A Usage Window uses an explicit time zone, day set, and half-open interval, may cross midnight, and attributes an entire inference attempt by its start time; v1 does not embed holiday calendars.
