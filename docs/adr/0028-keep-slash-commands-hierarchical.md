# Keep slash commands hierarchical

GreenTyper will keep the root Slash Panel to a small curated set of Command Paths such as `/config`, `/model`, `/stats`, `/agent`, and `/blockers`, then reveal nested actions only after entering their scope. Prefix and fuzzy matching operate token by token, the global command palette may search all nested and recent actions, and slash commands navigate to focused dialogs rather than encoding configuration mutations in long flat names; headless callers retain typed CLI and App Server operations over the same Config Schema.
