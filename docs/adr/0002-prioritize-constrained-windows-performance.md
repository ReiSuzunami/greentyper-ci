# Prioritize constrained Windows performance

GreenTyper will optimize for responsive operation and minimal total resource use on constrained Windows laptops, even when this requires dropping broad platform, CPU, or legacy-interface compatibility. The initial Target Machine is a Windows 11 Latest RedmiNotebook 2022 with 16 GB RAM under roughly 80% normal background memory use; the design uses the weakest plausible 16 GB configuration as its provisional floor, targets an x86-64-v3 optimized distribution, and lets the first asynchronous Acceptance Run fingerprint the exact SKU and confirm required CPU features. FMDev, a freely configurable Windows 11 virtual machine with four AMD EPYC 4584PX vCPUs and 8 GB RAM, is the continuous Validation Host, while the macOS ARM machine and GitHub-hosted CI cover development and correctness and absolute release gates await asynchronous Target Machine runs during the user's workday availability.
