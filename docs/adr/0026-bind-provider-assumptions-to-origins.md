# Bind Provider assumptions to origins

Provider Template endpoints remain user-overridable, but changing a Provider Origin never carries an official credential or origin authority to the new endpoint. When a template has a reviewed, versioned release-bundled rate card, a custom origin defaults to a frozen `template_mirror` estimate with distinct provenance; an explicit `unknown`, `manual`, or trusted `provider_reported` decision overrides it. Templates without a bundled rate card still require an explicit pricing decision. A mirrored rate card is only an estimate and does not assert the gateway's hidden backend identity. Custom origins require an explicit credential binding, use HTTPS except for loopback or an explicit insecure opt-in, and remain distinct Provider Profiles in usage statistics.
