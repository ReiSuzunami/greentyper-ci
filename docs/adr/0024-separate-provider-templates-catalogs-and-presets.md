# Separate Provider Templates, Model Catalogs, and Model Presets

GreenTyper will ship versioned Provider Templates and a release-bundled seed Model Catalog for OpenAI, DeepSeek, and OpenCode Go, including their official default endpoints, while every configured Provider Profile may override its base URL and declared routes for a user-operated gateway and Model Presets remain the user-facing runnable choices. Creating an official profile offers versioned starter presets from the release snapshot; accepted starters become user-owned configuration and are never rewritten silently. The initial dialect set covers OpenAI Responses, OpenAI Chat Completions, and Anthropic Messages; lazy provider discovery and explicit overrides may augment the catalog with field-level provenance and freshness, but remote catalog data may not inject credentials, arbitrary endpoints, instructions, or capabilities. A Provider Profile may route different models through different declared Provider Dialects because services such as OpenCode Go expose heterogeneous APIs under one account.
