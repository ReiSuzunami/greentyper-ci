# Security Policy

## Supported Versions

GreenTyper has not reached an Alpha release. No version is currently supported for production use.

## Reporting a Vulnerability

Do not open a public issue in the temporary CI mirror. Report suspected vulnerabilities privately to `i@rei.rs` with the affected revision, impact, and a minimal reproduction when possible.

Never include credentials, private prompts, user content, or unredacted provider traffic. Receipt will be acknowledged within seven days; remediation and disclosure timing will depend on severity and whether the affected behavior has shipped.
